# Aster Heating & Air

A premium, conversion-focused website for a residential HVAC company serving
Westchester and Fairfield County.

## Highlights

- Responsive, editorial luxury-home design
- Repair, replacement, indoor-air-quality, and membership offers
- Click-to-call actions and appointment request form
- Bespoke Open Graph social preview
- Accessible labels, keyboard-friendly controls, and reduced-motion support
- Ready for Railway deployment

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm start
```
